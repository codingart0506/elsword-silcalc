# 엘소드 실투력 계산기 · 화면인식 자동기입

사이트: https://codingart0506.github.io/elsword-silcalc/

- 상세 스탯 창을 화면 공유로 캡처하거나 스크린샷(PrtSc → Ctrl+V)을 붙여넣으면 기본 능력치를 자동으로 채워요.
- 같은 스크린샷의 장비창에서 전직 초상화와 일반 악세서리 아이콘도 알아봐요(처음 보는 건 한 번 골라주면 기억).
- 입력값은 이 브라우저에만 저장돼요.

계산 공식은 **[실질전투력] Actual Combat Power** 시트(제작 마음담은편지)의 수식을 그대로 옮겼어요.
글자 인식: Tesseract.js (Apache-2.0)
